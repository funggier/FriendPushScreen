# Changelog

## 1.0.0 — 2026-10-17

Initial published native Windows release.

- H264 screen/window/capture-card sharing with independent CPU/GPU encode/decode controls.
- Mutually pinned QUIC video, optional WASAPI/Opus audio and receiver output/mute/volume controls.
- One Host / IP and Remote Port for IPv4 and bounded asynchronous DNS/DDNS resolution.
- One saved paired device with persistent authorization removal and explicit fingerprint re-pairing.
- Live peer Ping/Send/View FPS, clean borderless viewer and saved whole-status-strip visibility.
- Settings/status/Diagnostics painting repairs.
- Portable Windows x64 archive, tagged source/document archives, Thai guide and SHA256/identity manifest.

See docs/releases/v1.0.0.md and the dated qualification reports for actual test scope, retained failures and remaining network/recovery gates.
