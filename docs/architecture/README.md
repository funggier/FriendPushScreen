# Architecture Documentation

The V1 master architecture is defined in:

`../development-plan/ScreenLink_V1_Architecture_and_Development_Plan_TH.md`

This directory is for decisions that refine or supersede specific architecture choices after evidence is collected.

## Decision policy

- Do not create an ADR merely to restate the master specification.
- Create an ADR when a real choice is resolved and later tasks need that decision to remain stable.
- Record measurements, compatibility findings, licensing constraints, and rejected alternatives.
- If a decision changes, add a superseding ADR instead of silently rewriting history.
- Keep implementation-specific decisions separate from future V2 feature ideas.

See `DECISION-GATES.md` for unresolved choices that must not be guessed early.
