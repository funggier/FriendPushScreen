## Included behavior

- Native Win32/D3D11 capture/viewer with H264, independent encoder/decoder CPU/GPU choices and configurable video details.
- Pinned, mutually authenticated QUIC peer video and optional WASAPI/Opus shared audio; selectable playback output, mute and volume.
- One Host / IP plus Remote Port for IPv4/DNS routes; no Connection Mode selector.
- Persistent one-device pairing with full fingerprint confirmation and Remove Paired Device. Removal stops the active connection and remains removed after restart.
- Application Ping and measured Send/View FPS; persisted whole-status-strip hiding, Borderless/Tab/fullscreen access.
- Prior Settings/Hide Settings/Diagnostics painting repairs and regression coverage.

## Known limits preserved

- DDNS tests reached the same physical PC through the public-name/NAT-loopback route: around30fps per direction in the recorded short run; self-LAN around60fps.
- The own-Tailscale-IP run connected but had one video recovery and changed generations. Strict continuity failed and earlier intermittent recovery evidence remains retained.
- Alternate127.0.0.2 failed raw MsQuic with CONNECTION_IDLE even though raw UDP worked; ordinary127.0.0.1 and the documented routes passed.
- Physical second-PC WAN/LAN/Tailscale Direct/DERP, IPv6 endpoint input, remote clock/A-V synchronization, comprehensive endpoint/network fault recovery and wider GPU/Windows compatibility are unqualified.
- The identical-encoded-workload TLS/TCP/control/synthetic-audio comparison and permanent DG001 choice remain open. Broader DG006/DG008 and full V1 acceptance/installer milestones remain open.
- Application/process-loopback audio is unavailable on the Windows19045 reference host. Route runs here used No Audio; localhost optional-audio evidence is in its own report.
- The application EXE is unsigned. This portable release has no installer or uninstall/over-install qualification.

Version1.0.0 and the normal release filename follow the user's explicit version selection. The release preserves the measured feature boundary above. No main merge, historical tag move, firewall/router, certificate-store or OS-security change is part of publication.
